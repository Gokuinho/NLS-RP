# Lexique

Les termes ci-dessous sont utilisés partout dans le règlement et par le staff. Ceux marqués **⛔** désignent des comportements interdits.

| Terme | Définition |
|---|---|
| **RP / HRP** | *Roleplay* : ce que vit votre personnage. *Hors-RP* : ce que vit le joueur derrière l’écran. |
| **⛔ PowerGaming** | Imposer une action irréaliste ou forcer son résultat sans laisser aux autres joueurs une possibilité raisonnable de réagir. |
| **⛔ MetaGaming** | Utiliser en jeu une information obtenue hors RP : Discord, stream, discussion vocale HRP, autre personnage. |
| **⛔ Stream-hack** | Forme de métagaming : regarder le live d’un joueur pour le localiser ou connaître ses plans. |
| **⛔ Double vocal** | Forme de métagaming : échanger avec d’autres joueurs sur un vocal externe pendant une scène. |
| **⛔ Fail RP** | Agir d’une manière qu’aucune personne réelle n’adopterait dans la même situation. |
| **⛔ NoFear** | Ne pas craindre pour sa vie : ignorer une arme pointée, provoquer un groupe armé, refuser d’obéir sans moyen crédible de s’en sortir. |
| **⛔ NoPain** | Ignorer ses blessures : courir, conduire ou se battre normalement après avoir été blessé. |
| **⛔ RDM / FreeKill** | Tuer ou tenter de tuer un joueur sans contexte ou interaction RP suffisante. |
| **⛔ VDM** | Utiliser volontairement un véhicule comme arme sans justification RP valable. |
| **⛔ CarKill** | Se servir d’un véhicule comme arme principale dans un affrontement. |
| **⛔ Revenge Kill** | Revenir se venger d’une scène après être tombé dans le coma, alors que votre personnage a oublié la scène (voir [Coma](coma-mort-rp.md)). |
| **⛔ Combat Log** | Quitter volontairement la session afin d’éviter ou d’interrompre une scène RP en cours. |
| **⛔ Force RP** | Enfermer un joueur dans une scène qu’il n’a aucun moyen de jouer ni de refuser, ou l’empêcher de jouer la sienne. |
| **⛔ Freeloot** | Fouiller et vider quelqu’un sans scène qui le justifie, ou prendre plus que ce que la scène permet (voir [Loot et arnaques](../illegal/loot-arnaques.md)). |
| **⛔ Usebug** | Exploiter un bug du jeu ou d’un script à son avantage. |
| **⛔ Mass RP** | Rameuter un nombre disproportionné de personnes sur une scène, ou forcer toute la ville à tourner autour de soi. |
| **PIT** | Manœuvre qui consiste à pousser l’arrière d’un véhicule pour le faire pivoter et l’arrêter. Réservée aux forces de l’ordre lors d’une poursuite (voir [Police](../legal/police.md)). |
| **Coma** | État d’un personnage mis à terre : il ne parle plus et n’agit plus. |
| **Mort RP** | Fin définitive d’un personnage, validée par le staff. |
| **CK** | *Character Kill* : mort RP imposée à un personnage au terme d’une procédure validée. |
| **Zone safe** | Lieu où toute action hostile est interdite (voir [Zones safe](zones-safe.md)). |
| **Référent** | Membre du staff chargé de suivre les structures légales ou illégales. |
| **GM** | *Game Master* : membre du staff qui joue un PNJ ou encadre un événement. |
| **Wipe** | Réinitialisation d’un personnage (voir [Personnage et wipe](../general/personnage.md)). |
