# Tutoriels

Les étapes pour rejoindre la ville, régler le micro et résoudre les problèmes courants.

## Première connexion

* Rejoignez le [Discord principal](https://discord.gg/JcSVkPKFrY) et acceptez le règlement avec le bouton du [salon règlement](https://discord.com/channels/1545172746873348199/1545213150188806197) pour obtenir **Citoyen**.
* Lisez le règlement, notamment les pages Global et les [Notions du RP](notions.md).
* Utilisez **GTA V** légalement acquis sur Steam, Epic Games ou Rockstar Games Launcher, à jour, avec un micro fonctionnel.
* Téléchargez FiveM uniquement sur [fivem.net](https://fivem.net), puis lancez l’installateur.
* Laissez FiveM détecter GTA V et télécharger ses fichiers ; connectez le compte **Cfx.re** lorsqu’il le demande.
* Récupérez le lien de connexion uniquement dans les [annonces](https://discord.com/channels/1545172746873348199/1545213151555878912).
* Ouvrez ce lien ou utilisez **F8**, puis `connect` suivi de l’adresse.
* Attendez la fin du premier chargement, parfois long, sans fermer le jeu.
* Créez un personnage conforme au [Règlement HRP](../global/hrp.md), puis réglez votre micro.

{% hint style="warning" %}
Un mod interdit entraîne un **bannissement permanent**, même installé par erreur. Consultez les mods autorisés dans le [Règlement HRP](../global/hrp.md).
{% endhint %}

## Vider le cache FiveM

* En cas de crash, de textures manquantes ou de connexion bloquée, fermez complètement FiveM ; vérifiez la barre des tâches.
* Ouvrez **Windows + R**, saisissez `%localappdata%\FiveM\FiveM.app\data`, puis validez.
* Supprimez uniquement les dossiers `cache`, `server-cache` et `server-cache-priv`.
* Conservez `game-storage` : sa suppression impose de télécharger de nouveau les fichiers du jeu.
* Relancez FiveM et reconnectez-vous ; le premier chargement sera plus long.
* Si le problème persiste, ouvrez un ticket **Bug** avec l’erreur exacte, une capture et les solutions déjà essayées.

## Régler le micro

* Dans FiveM, ouvrez **Paramètres → Voice Chat** et activez le chat vocal.
* Sélectionnez votre micro comme périphérique d’entrée.
* Choisissez *Push-to-talk* pour limiter les bruits et réglez le volume sans saturation.
* Aucun bruit permanent, musique ou soundboard ; adaptez votre portée de voix avec la touche prévue : chuchoter, parler ou crier.
* Utilisez la radio et le téléphone du jeu ; un vocal Discord pendant une scène constitue du *Double vocal*.

## Micro non détecté

* Dans **Paramètres Windows → Confidentialité → Microphone**, autorisez FiveM à utiliser le micro.
* Après branchement du micro, relancez FiveM.
* Si le problème continue, ouvrez un ticket **Bug** avec une capture des paramètres vocaux.
