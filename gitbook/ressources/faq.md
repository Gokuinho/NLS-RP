# FAQ

Les réponses rapides aux questions courantes ; pour un doute, ouvrez un ticket.

## Accès et débuts

* **Comment rejoindre ?** Consultez uniquement les [annonces](https://discord.com/channels/1545172746873348199/1545213151555878912) pour les modalités d’accès, la whitelist éventuelle et le lien de connexion ; suivez les [Tutoriels](tutoriels.md).
* **Débutant accepté ?** Oui : lisez les [Notions du RP](notions.md), commencez avec un personnage simple et demandez de l’aide par ticket.
* **Où sont les liens officiels ?** Sur la page [Liens utiles](liens.md).
* **Comment obtenir Tag NLS ?** Ajoutez `[NLS]` à votre pseudo Discord ; le rôle est automatique.

## Aide et incidents

* **Contacter le staff ?** Uniquement par [ticket](../global/discord.md) ; les messages privés ne sont pas traités.
* **Règle peu claire ?** Ticket **Support général** ; une question récurrente conduit à préciser le règlement.
* **Perte liée à un bug ?** Ticket **Remboursement** avec preuves ; sans preuve, la demande ne peut aboutir. Voir le [Règlement HRP](../global/hrp.md).
* **Sanction contestée ?** Ticket **Contestation de sanction**, jamais en public ; consultez les [Sanctions](../global/sanctions.md).
* **Crash ou connexion bloquée ?** Suivez le nettoyage du cache dans les [Tutoriels](tutoriels.md), puis ouvrez un ticket **Bug** si nécessaire.

## Participer

* **Rejoindre le staff ?** Consultez les annonces et le salon [recrutement-staff](https://discord.com/channels/1545172746873348199/1551524353605238796) ; candidature spontanée par ticket **Candidature**.
* **Streamer ?** Oui ; le rôle et le programme créateur sont décrits dans le [Règlement Discord](../global/discord.md).
* **Rejoindre une structure ?** En jeu, par le RP ; pour créer un groupe ou reprendre une entreprise, consultez le [Règlement illégal](../illegal/reglement-illegal.md) ou les [Entreprises](../legal/entreprises.md).
