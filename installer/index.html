Installer le bot

NLS | RP est un bot privé, réservé aux serveurs Discord de NEW LOS SANTOS | RP. L’ajout est autorisé pour la Direction uniquement.

Ajouter NLS | RP à un serveur

Après l’ajout
  1. Paramètres du serveur → Rôles : place le rôle NLS | RP juste sous le rôle Fondateur. Un bot ne peut agir que sur les rôles situés sous le sien.
  2. Vérifie que les permissions demandées sont cochées : Administrateur, Voir les logs du serveur, Gérer le serveur, Créer une invitation, Mentionner @everyone.

En ajoutant le bot, tu acceptes les conditions d’utilisation et la politique de confidentialité.
